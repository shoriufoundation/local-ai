# Local AI

**Local AI powered by OpenRouter & NVIDIA Nemotron — Shoriu Foundation**

A lightweight local AI application powered by **OpenRouter** and **NVIDIA Nemotron**, developed by **Shoriu Foundation**.

## ✨ Features

* 🤖 AI-powered chat
* ⚡ NVIDIA Nemotron support
* 🌐 OpenRouter API integration
* 💬 Message history
* 🖥️ Simple web interface
* 🏠 Runs locally on your own machine
* 🔐 API key configured through `.env`

## 📁 Project Structure

```
local-ai/
├── .env
├── main.js
├── messages.json
├── package.json
├── server.js
└── public/
    └── index.html
```

## 🚀 Installation

### 1. Clone the repository

```
git clone https://github.com/ShoriuFoundation/local-ai.git
cd local-ai
```

### 2. Install dependencies


npm install


### 3. Configure the API key

Open `.env` and add your OpenRouter API key:

```
OPENROUTER_API_KEY=your_key_here
```

### 4. Start the application

```
node server.js
```

Then open the local address shown by the server in your browser.

## 🧠 AI Provider

This project uses **OpenRouter** as the API provider and supports **NVIDIA Nemotron** models.
